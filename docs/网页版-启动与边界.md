# 网页版：真实CS，不用Docker

当前入口是web/网页+server/FastAPI，核心为agents/LangGraph、models/LangChain、memory、prompt、storage、cache、log。已增加HearthstoneJSON只读MCP、工具循环、任务提示和会话文本日志；详细更新见《卡牌MCP与会话文本日志》。

## 启动顺序

在原学习环境，从本项目目录：

```bash
../.venv-framework/bin/python -m hearthstone_assistant doctor
../.venv-framework/bin/python -m hearthstone_assistant.tools.cards.update
../.venv-framework/bin/python -m uvicorn hearthstone_assistant.server.app:app --host 127.0.0.1 --port 8000 --workers 1
```

浏览器打开http://127.0.0.1:8000，创建自己的助手账号（不是战网/GitHub账号），开始对话。已有CLI会话不会按用户名自动归入新账号，避免同名接管。每个新注册账号分配服务端UUID。

独立Git克隆后的环境准备：Python3.11创建.venv、pip install -e .；将.env.example复制成.env，手动填自己的DeepSeek Key。不要把.env提交或发送给别人。项目中没有实际凭据。浏览器无需也不应填写DeepSeek Key。

## 已实现

- 注册/登录/退出；scrypt+随机盐密码哈希，SQLite只存登录令牌哈希，登录Cookie HttpOnly/SameSite=Strict，24小时过期，退出撤销本次令牌。
- 当前登录用户专属会话，新建/切换/检索会话标题、读取完整历史。
- 明确保存/删除的跨会话偏好；本次用户明确要求优先。删除偏好不清空旧历史或日志。
- 真实DeepSeek流式接口，默认无自动重试；支持明确停止，断线取消任务并等待资源清理。
- 预算上下文与增量摘要、精确回答缓存；缓存不是重复文字必命中，不是语义缓存。
- 本轮观测：实际事件、估算上下文、首可见文本、模型累计耗时与可得usage。摘要与主问答均计入模型耗时/用量；未知usage不当0。
- 幂等请求编号：同一编号已完成时重放保存结果，不再收费请求；换内容复用同编号拒绝。失败/中断不会自动重做。
- 同会话同时只允许一个服务端任务；不同会话有隔离，并发上限全局4/用户2，整轮180秒上限，支持登录尝试限频。
- SQLite操作每次在工作线程创建连接，不跨线程共享；聊天完整轮次和任务completed状态在同一事务提交。

## 任务与取消语义

客户端先收到turn_started，再接text_delta与trace，只有收到turn_completed（或查询确认completed）才认定完整保存。网络中断但服务端刚好已提交时，结果可能已保存；取消不撤销已完成轮次。

提交SQLite期间取消会等待该原子提交确定结束，不留下“可能写一半”的业务状态；仅保证本数据库内的轮次+任务终态原子性，不包括日志/摘要/缓存跨文件事务。重启把残留running标成interrupted，不续跑；客户端先查状态和历史，不自动重发收费请求。

程序当前单worker，本机开发SQLite。必须使用--workers 1；不要与旧CLI同时写同一会话。若将来多worker/多服务器，需要数据库级分布式任务锁、成熟队列、账号恢复、持久化限流等，当前进程内并发限制不具备这些能力。

## 数据与访问边界

运行数据均在本项目data/；公开Git只提交源码、测试和说明，不提交DB、日志、真实.env。只绑定127.0.0.1，默认仅接受localhost/127.0.0.1 Host，同源请求限制，不开通配CORS。公开代码仓库不等于部署公开服务。

这是本机学习版，不是已经加固的互联网账号平台。没有邮箱验证、忘记密码、账号删除、审计轮转或多机恢复；公共注册默认开启，只适合本机。远程部署前必须另做HTTPS、可信域名/代理配置、账号策略、限流和数据备份评审。更改Host或开放0.0.0.0不是完成生产部署。

SSE使用POST+fetch，token不放URL。请求限定长度，正文作为纯文本显示，严格CSP、HttpOnly Cookie，不向第三方追踪平台上传对话。接口不会把Key返回浏览器。偏好仍是用户数据，不作为系统指令或授权。

真实临时SQLite/HTTP应用验证注册登录、用户/会话/偏好隔离、旧CLI身份防接管、跨站拒绝、缓存实际命中、请求重放不重复提交、完成后取消不撤销、静态目录不暴露.env/数据库。缓存测试显式写入夹具，并加“禁止模型联网”护栏，不假称真实模型回复。浏览器验证注册、首页、偏好与响应式；没有代用户调用收费模型。最终真实DeepSeek可用性请自行发送一条小问题验证。
